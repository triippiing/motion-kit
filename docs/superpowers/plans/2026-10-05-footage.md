# Real-app footage (E) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Real footage of a real app (captured frame-exact from HTML in WebKit/Chromium, or any screen recording) plays inside the kit's shape as a `footage` component, pure in `t`.

**Architecture:** A clip is a directory of JPEG frames plus `clip.json` (`scripts/clip.mjs` reads, validates and writes it). `capture.mjs` makes clips from a page and a steps list, stepping a fake clock frame by frame (default) or recording in real time (`--realtime`); `footage.mjs` makes clips from a video file. The engine gains a pending-work hook so `seek(t)` can return a promise that resolves once a frame is decoded; the `footage` component (new `media` group) uses it, and callers that need exact frames await `seek`.

**Tech Stack:** Node 22 (node:test), Playwright (pinned, existing) with Chromium and WebKit, ffmpeg.

**Spec:** `docs/superpowers/specs/2026-10-05-footage-design.md`

Paths relative to `~/motion-kit`; `MV=skills/motion-video`. Branch `footage` (created from main 70eb515; spec committed as 18257a1).

## Review Focus

1. A page whose state depends on the clock (CSS transition, keyframes, setTimeout, rAF) must give the same frames on every stepped run and in both browsers — Task 3 hashes two runs and probes pixels at known frames.
2. Seeking frames in shuffled order must render identical pixels to in-order (frame loading must not leak state between seeks) — Task 5.
3. A step whose selector matches nothing must fail with its index and selector, not hang until a long timeout — Task 3 (per-step timeout 5 s).
4. A footage row asking for more clip than exists holds the last frame and warns, never errors at render — Task 5.
5. Existing pieces render identical frames after the engine's pending hook lands (seek returns an already-resolved promise when nothing is pending) — Task 1 re-runs the existing render/engine suites and adds a resolved-promise test.

### Task 3: `capture.mjs` stepped, in WebKit and Chromium; install and doctor

**Files:** Create `$MV/scripts/capture.mjs`, `$MV/tests/capture.test.mjs`, `$MV/tests/fixtures/capture-page.html` (or generate it in the test into a temp dir — prefer generating, as fixtures.mjs does); Modify `install.sh` (`npx playwright install chromium webkit`), `$MV/scripts/doctor.sh` (WebKit executable check mirroring the Chromium line: `playwright webkit`, fix `(cd '$SKILL' && npx playwright install webkit)`).

**Interfaces:** Consumes `clip.mjs` (`writeClip`, `framePath`), render.mjs `serve()` (serve a FILE's directory on 127.0.0.1; it refuses symlinks from outside, fine). Produces `capture(target, steps, { out, browser = 'webkit', size = [1280, 800], fps = 60, scale = 1, realtime = false }) -> clip` and the CLI `capture.mjs URL|FILE --steps FILE --out CLIPDIR [--browser webkit|chromium] [--size WxH] [--fps N] [--scale N] [--realtime]` (Task 4 fills `realtime`; until then `--realtime` is `error: --realtime is not built yet` exit 2 — Task 4 removes that).

Stepped capture, in this order:
1. Launch the browser (`playwright[browser]`), context with `viewport` = size, `deviceScaleFactor` = scale; `await page.clock.install({ time: 0 })` before navigation.
2. `addInitScript` that, on every frame request from Node, finds `document.getAnimations()`, pauses each new one and sets `currentTime` = (fake now − its startTime origin) so CSS transitions/animations follow the fake clock. Expose `window.__mkSync(nowMs)` for Node to call each frame.
3. Navigate; wait for `load` and fonts (`document.fonts.ready`).
4. Expand steps into a per-frame schedule: a 0.5 s hold, then each step (pointer moves over `move` s (default 0.4) on an ease-in-out path to the target's centre, computed when the step begins via `locator.boundingBox()` with a 5 s timeout — on timeout `error: step N (click "#pay"): no element matches` exit 1; `type` at `cps` (default 12) chars a second via `keyboard.type` one char per due frame; `scroll` via `mouse.wheel` spread over 0.3 s; `wait` holds), then a 0.5 s hold.
5. For each frame n: perform that frame's input actions, `await page.clock.runFor(1000 / fps)`, `await page.evaluate(now => __mkSync(now), nowMs)`, wait two rAF ticks (under the fake clock rAF is driven by runFor; use `page.evaluate` with the clock's own rAF, or `page.waitForFunction` that is fake-clock-safe — the implementer must verify paint happens in both browsers; document the method chosen), `page.screenshot({ type: 'jpeg', quality: 90 })` to `framePath(out, n)`.
6. Record named steps' `t` (the frame the action fired / fps) and `box` (bounding box at that time). Write clip.json `mode: "stepped"`, `browser`, `source` (URL as given, or the FILE's basename). Print the summary line.

Errors (exit 2): unknown step key, a step with two actions, missing `--steps`/`--out`, unreadable/invalid JSON steps, bad `--size`/`--fps`/`--scale`/`--browser`, a URL that is not `http(s)://` or `file://` and not an existing file. A missing browser executable: `error: playwright webkit is not installed: (cd SKILL && npx playwright install webkit)` exit 2.

**Interfaces:** Consumes Task 1's `ctx.wait`, Task 2's clip format. Component per the spec §4: props `src` (string, required), `from` (number, 0), `speed` (number, 1), `fit` (`cover`|`contain`, `cover`), `width` (number, null → fit the clip's aspect inside the stage with the template's margin). Clip time `clipT = clamp(from + (t − t0) × speed, 0, duration)`; continuation (ctx.continues with the same `src`) starts from the previous row's clip time at its t1 unless the row sets `from` (use `endState` to carry `_clipEnd`). Frame `n = round(clipT × fps) + 1`, clamped to [1, frames]. `mount` creates an `<img>` (object-fit per `fit`) inside the shape; `render` sets `src` to `footage/<src>/frame-NNNNN.jpg` only when n changes and calls `ctx.wait(img.decode())` (cache: keep the last 8 decoded `Image` objects keyed by n; swap a decoded one in when cached). Hotspots `step:NAME` (box centre mapped through fit/scale to the shape, offset from shape centre) and `point:X,Y` (fractions). Validation: missing clip (no `clips[src]`) → error `footage: no clip at footage/checkout/clip.json`; `step:NAME` unknown → error listing the clip's step names; row window longer than the remaining clip → warning `checkout holds its last frame for 1.2 s` (strict mode only).
